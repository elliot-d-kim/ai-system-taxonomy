# ai system taxonomy

- contextual ui -- software it lives in (notion, excel, cursor) ⭐
- model ⭐
- i/o modality -- text/image/video/file ⭐
- basic steerability -- prompt, system instructions, presets ⭐
- prompt library -- skills, gems 🚀
- memory
- context assembly -- at-will injection of existing resources (skills, connectors, urls, etc.) 🚀
- multi-turn
- regenerate/edit message/branching
- triggers -- scheduled, event-based, intelligent 🚀
- agentic loop 🚀
- human-in-the-loop -- always ask vs auto-approve
- ephemeral ui -- in-chat widgets (confirm button)
- connectors, read-only -- internet, internal systems ⭐
- connectors, read/write -- internal systems, communications (e.g., slack, email), apps 🚀
- citations -- granularity in output, granularity in source ⭐
- artifact management -- file system, portability, coupled to vs decoupled from chat 🚀
- version control -- view diff, undo changes 🚀
- code execution 🚀
